# 🍽️ Restaurant Table Reservation System

## Project Description
A web-based restaurant table reservation system that allows customers to reserve tables easily through an interactive and user-friendly interface.

## Features
- 🍽️ Restaurant table booking
- 👤 User-friendly interface
- 📱 Responsive design
- 📅 Reservation management
- 🔍 Simple navigation
- ✅ Booking confirmation system

## Technologies Used
- HTML
- CSS
- JavaScript
